PolicyHub — build 2026-09-09a
Minimal update. Paths are relative to the `policyhub` folder of your repo.

WHAT CHANGED

  Changing death benefit    A tick box on an opportunity. When it is on,
                            the premium schedule gains a Death benefit
                            column — one figure per policy year — and the
                            return is solved on the benefit in force on
                            each maturity date rather than on one face
                            amount for all three scenarios.

                            Each figure stands from its own date until the
                            next one, so a blank year pays what the year
                            before pays. Past the end of the schedule the
                            last figure is HELD LEVEL, not extrapolated.

  The one-pager             Per-scenario death benefit in the HTML sheet
                            and the PDF, a Death benefit column in the
                            year-by-year table, and the assumption stated
                            on the document.

  Two bugs found on the way
                            - The PDF one-pager printed the constant face
                              amount in all three scenario rows while the
                              HTML sheet printed a per-scenario figure.
                              They had already disagreed for an investor
                              viewing net of carried interest.
                            - The opportunities list builds its own SQL
                              rather than SELECT *, so a new column has to
                              be added there by hand or the list and the
                              detail quote different rates for one deal.

  should read 2026-09-09a. No database step, no new environment

HOW TO USE IT
  Opportunity -> Edit -> tick "Changing death benefit" -> Save.
  Then Premium schedule: the Death benefit column is there, one row per
  year. Type only the years that step; leave the rest blank.
