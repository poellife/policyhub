PolicyHub build 2026-11-08c: carried interest is for administrators only
(Includes everything since 2026-11-01a: compounding, multi-entity investors,
the CFO login. Upload this one zip; skip the earlier ones.)

Upload into the policyhub folder of the repo:
  src/      -> policyhub/src      (api.js, auth.js, schema.sql, opportunity-pdf.js,
                                   opportunity-email.js, maturity-pdf.js)
  public/   -> policyhub/public   (app.js, reports.js, irr.js, build.js, styles.css)
  scripts/  -> policyhub/scripts  (tests, optional)

What changed in this build
- Carried interest, commission and "net to investors" are now shown to
  administrators only. Editors, viewers, portfolio managers, investors and
  CFO logins no longer see the dashboard tile, the entity rate column, the
  entity form's carried-interest section, or the maturities columns, and
  the server no longer sends them those figures at all.
- An editor can still edit an entity's code, name and notes, but not its rate.
- Investors' own figures are still net of carry, as before; nothing names it.
