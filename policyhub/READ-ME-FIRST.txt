Change: Mortality Watch no longer searches on its own. A search runs only when
an administrator presses "Run now" on the Mortality Watch page.

If Render has an environment variable MW_SCHEDULE set to "on" or "daily",
remove it (or set it to "off"), or the daily search will keep running.
To bring the daily search back later, set MW_SCHEDULE=on in Render.
