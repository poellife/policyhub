PolicyHub build 2026-11-08a: an investor can belong to more than one owner entity

Upload into the policyhub folder of the repo:
  src/      -> policyhub/src      (api.js, schema.sql)
  public/   -> policyhub/public   (app.js, styles.css, build.js)
  scripts/  -> policyhub/scripts  (tests, optional)

If you have NOT yet uploaded build 2026-11-04a (compounding), upload that zip
first, or its features will be missing. These files already include it.

Database: a new table, investor_funds, is created automatically on the next
start. Every investor's existing entity is copied into it, so nothing is lost.

What changes
- Edit investor -> "Owner entities" is now a list of tick boxes. Tick as many
  as apply; untick all for "not assigned".
- Every manager of any ticked entity sees the investor in their list.
- The Investors list shows all of them, e.g. "LCG1, LCG2", and the entity
  filter finds the investor under each one.
- Still administrator-only. Each change is written to the activity log.
