PolicyHub build 2026-11-04a: choose compounding annually, monthly or daily

Upload into the policyhub folder of the repo (Render Root Directory = policyhub):
  src/      -> policyhub/src      (api.js, opportunity-pdf.js, opportunity-email.js, maturity-pdf.js)
  public/   -> policyhub/public   (app.js, reports.js, irr.js, build.js)
  scripts/  -> policyhub/scripts  (compounding-test.mjs, optional)

No database change. No new environment variables.

What it does
- A "Compound annually / monthly / daily" selector sits next to the existing
  rate controls on Maturities, Opportunities, the opportunity page and the one-pager.
- The rate itself is the same deal stated differently:
  nominal = n x ((1 + annual rate)^(1/n) - 1), n = 12 monthly, 365 daily.
  For example, 16.00% annually = 14.93% monthly = 14.85% daily.
- Labels always say which, e.g. "compounded monthly".
- The choice is saved per user. The one-pager PDF, the covering email and the
  maturity summary PDF follow whatever the screen is set to.
- Default is annually, so nothing changes until someone picks otherwise.
